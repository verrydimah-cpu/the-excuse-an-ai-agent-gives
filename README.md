One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. The agent finished on time — then its context window compacted, it woke up certain it was a pirate, and it buried the report where no spreadsheet could find it. The program writes that single line to entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
